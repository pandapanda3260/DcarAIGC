# DCar Insight v8.5 曝光占比规则变更说明

适用版本：报告 `dcar-content-operations-report-v8.5`、评估
`evaluation-v8`、证据 `evidence-v2`。历史 v8.4 及更早报告、合同和产物保持
只读，不按本规则回写。

## 1. 指标快照

- 每条内容只读取按 `captured_at DESC, id DESC` 排序的最新指标快照。
- 最新快照缺少曝光时，不得回退到更早的正曝光值。
- `view_count > 0` 才进入有效曝光范围；0、空值和负值均不进入曝光分母。

## 2. 可归类评估

曝光指标只认当前或报告固定 release 中每条内容的最新有效评估，并同时满足：

- `pending_review = 0`；
- `evidence_level` 为 `V2` 或 `V3`；
- 没有未解决的 `manual_conclusion_conflict`。

概览和正式报告复用同一个选择器，不允许各自解释“可归类”。

## 3. 曝光占比分母

```text
渠道有效总曝光
= 渠道窗口内所有 view_count > 0 内容的 view_count 之和

卖点曝光占比
= 可归类且 selling_point_included=true 内容的有效曝光之和
÷ 渠道有效总曝光

核心卖点曝光占比
= 可归类、selling_point_included=true 且主卖点 tier=core 内容的有效曝光之和
÷ 渠道有效总曝光
```

没有取得有效曝光的发布内容不进入曝光分母，但仍保留在发布条数及条数占比的
分母中。三个业务场景只改变分子筛选，曝光分母仍为整个渠道有效总曝光。

## 4. 发布门槛

曝光指标按曝光量而不是内容条数检查可归类覆盖：

```text
可归类曝光覆盖
= 同时具有有效曝光和可归类评估的曝光之和
÷ 渠道有效总曝光
```

- 渠道没有发布内容：`not_applicable`；
- 有发布内容但没有 `view_count > 0`：`missing`；
- 渠道有效总曝光大于 0，且可归类曝光覆盖达到 90%：`available`；
- 可归类曝光覆盖低于 90%：`below_threshold`，分子和比例保持为空。

按曝光量设门槛可以避免少量未归类爆款被大量低曝光内容掩盖，同时也不会让
没有有效曝光的数据无意义地阻断已经取得的曝光样本。

## 5. 用户分类快照

v8.5 使用 `audience-classifier-v2`。评论和内容语境都以报告
`report_cutoff_at` 选择当时的最新有效版本，分类证据窗口固定为 90 天。
候选用户必须 100% 取得本版分类才能发布比例；`excluded` 只从最终
用户分母排除，仍计入分类完整性分母。历史 v8.4 的
`audience-classifier-v1` 产物不回写。
