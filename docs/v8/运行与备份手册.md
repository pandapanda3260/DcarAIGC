# DCar Insight v8 运行与备份手册

## 环境与安装

- macOS Apple Silicon。
- Python 由 uv 管理并锁定为 3.12.13；系统自带 Python 3.9.6 不承载产品依赖。
- Node 运行时由 npm 命令固定为 22.13.1。

首次安装：

```bash
python3 -m uv sync --frozen
npm --prefix app/web ci
```

Python 依赖以 `pyproject.toml` 和 `uv.lock` 为准；前端依赖以 `app/web/package.json` 和 `app/web/package-lock.json` 为准。任何锁文件不一致都应先修复，不允许启动脚本隐式改锁。

## 启动与停止

```bash
scripts/start_web_mvp.sh
```

- Web：`http://127.0.0.1:4173`
- API：`http://127.0.0.1:8765`
- 退出：在启动终端按 `Ctrl-C`；脚本会同时停止 API 子进程。
- 调度和启动补跑默认均关闭；脚本启动时会打印两个实际开关值。
- 只开启后续日调度：`DCAR_SCHEDULER_ENABLED=1 scripts/start_web_mvp.sh`。
- 启动补跑还必须额外显式设置 `DCAR_STARTUP_CATCHUP_ENABLED=1`；补跑可能连续触发多个付费窗口，执行前必须单独确认成本。
- 每日采集固定使用北京时间，按最新内容优先；单次最多更新 3,000 条内容，TikHub 总预算硬上限 8 美元。
- 曝光历史修复先运行 `v8.range_backfill repair-metrics` dry-run；确认范围后加 `--apply`，再用 `fetch-repaired-metrics` 按平台、`--limit` 和 `--max-amount` 小批执行。

API 仅监听回环地址，不应直接暴露到局域网或公网。手机号搜索使用 POST body；服务日志只记录 URL path，不记录查询参数或请求体。

## 自动调度

时区固定为 `Asia/Shanghai`：

- 每日 02:00：账号发现和内容抓取。
- 每日 02:20：下载待处理媒体。
- 每日 03:00：处理本地媒体证据。
- 每日 07:30：执行媒体截止、增量评估和重复指纹处理。
- 每日 08:00：生成昨天日报。
- 每周一 08:30：生成上一个自然周周报。

服务只有在调度和启动补跑两个开关都显式打开时才执行有界补跑。抓取采用业务窗口成功槽：详情终身一次、指标每天一次、评论每周一次；失败在原槽重试。供应商余额、鉴权或预算异常会触发供应商级熔断，不会把排队或失败伪装成成功。报告运行门禁只会让日报或周报延期，不再连带关闭抓取、媒体处理和评估任务。

## 供应商与成本

- TikHub 凭据：项目外部本地凭据目录；详情、单条指标、评论、UID 转换和账号作品接口按已核验价格登记预算。
- Rnote 已退役，所有主动网络入口均在读取凭据、消耗预算或发起请求前以 `Rnote retired; use TikHub` 阻断；新发现、详情、指标、评论和媒体来源刷新统一使用 TikHub。
- 历史 Rnote 缓存、原始响应、用量记录和迁移/只读解析继续保留用于审计，不得删除，也不得据此恢复 Rnote 网络调用。
- 费用以 `provider_usage` 和 `provider_budget_batches` 为准；原始响应保存到 `data/cache/v8/raw_responses/` 并登记 SHA-256。
- 不在日志、报告、导出或 Git 中写入 API key、Cookie 或供应商 token。

## 逐 match 审计边界

当前 `evaluation-v8` 的逐 match 审计范围为卖点编码、业务场景、角色、分数、评分维度、来源、自然语言原因和证据片段；评估级 release、taxonomy、matcher 规则包 SHA 与 evidence envelope SHA 可追溯。当前版本不承诺表达式分支路径、稳定 reason code、原始 artifact 行 ID/SHA 或精确文本 span；这些能力归入 `match-provenance-v2`，必须通过新 matcher engine 与新 release 全量重评交付，禁止在现有 active release 内混写或改写历史记录。

## 数据备份

备份前无需停止服务，但必须使用 SQLite 在线备份命令，不能直接复制正在写入的 WAL 数据库：

```bash
mkdir -p backups
sqlite3 app/data/dcar_insight.sqlite3 ".backup 'backups/dcar_insight_YYYYMMDD_HHMMSS.sqlite3'"
```

随后备份不可重建证据与报告：

- `data/cache/v8/raw_responses/`
- `data/cache/v8/media/`
- `reports/runs/v8/`
- `config/report_contract_v8.json`
- `config/media_processor_v8.json`

恢复时先保留当前数据库，恢复备份文件到新路径，并用 `DCAR_V8_DB` 指向该路径启动验证；确认健康检查、任务 revision 和证据文件 SHA 后，才切换正式数据库。

## 完整验证

```bash
PYTHONPATH=src/dcar_eval:. .venv/bin/python -m unittest discover -s tests -v
.venv/bin/ruff check src/dcar_eval/v8 tests/test_v8_*.py
MYPYPATH=src/dcar_eval .venv/bin/mypy --follow-imports=skip src/dcar_eval/v8
npm --prefix app/web run lint
app/web/node_modules/.bin/tsc --noEmit -p app/web/tsconfig.json
npm --prefix app/web test
```

端到端验收至少覆盖：六类真实路由可访问、POST 搜索不泄露手机号、账号和内容 CRUD/CSV、逐条数据更新成功槽、人工复核生成新评估版本、感知重复指纹与定标状态、自定义报告生成和文件下载、v7 历史只读访问、服务重启后的调度补跑幂等。
