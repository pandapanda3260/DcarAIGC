# DCar Insight v8.3 规则变更说明

适用版本：报告 `dcar-content-operations-report-v8.3`、评估 `evaluation-v7`、证据 `evidence-v1`。未在本文修改的规则继续沿用 v8.2；`数据判定规则与算法说明_v8.2.md` 作为 `v8.2/evaluation-v6` 冻结历史保留。

## 1. 有效评论用户门槛

- 单条内容少于 5 名有效去重评论用户：互动用户垂直度、行动意图和拉新效果不出单条分数。
- 单条内容达到 5 名：沿用既有公式计算。
- 渠道汇总和三个业务场景仅对有分数的内容做等权平均；部分内容有分时返回实际数值，状态为 `sample_only`，并同时展示可评分条数、总条数和覆盖率。
- 评论门槛变化属于规则变化，不属于证据变化。v6 结果保留，v7 追加新版本；人工复核、迁移判定、卖点、方向和证据哈希原样继承，只重算评论派生分数。

## 2. 曝光数据有效性

- 账号作品列表中的播放/阅读量只有严格大于 0 时，才允许作为零费用指标快照并关闭当日指标槽。
- 作品列表返回 0 或缺失时，保留点赞、评论、分享、收藏，曝光写为缺失；不得阻止专用统计接口。
- 专用统计接口只更新实际返回的字段，不得用空值覆盖已有互动数据。
- 曝光占比仍执行 90% 的“内容标签 × 有效曝光”交叉覆盖门槛。供应商没有返回有效曝光时显示覆盖不足，不补值、不降低门槛。

## 3. 每日采集保护

- 时间和自然日统一使用 `Asia/Shanghai`。
- 每日采集按最新内容优先，内容更新队列上限为 1,200 条。
- 单次每日采集 TikHub 任务总预算上限为 3 美元；余额、鉴权或预算错误触发熔断。
- 历史错误曝光修复必须先 dry-run，再按平台、条数和任务预算执行；复用原槽并保留原始响应、尝试和费用记录。
