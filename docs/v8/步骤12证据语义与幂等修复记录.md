# 步骤 12：证据语义与幂等修复记录

执行日期：2026-08-02（Asia/Shanghai）

## 本步修改

- 证据包的 `detail_raw_sha256` 只接受抖音详情、小红书详情和历史小红书视频补证响应；statistics、metrics、comments 不再改变评估证据指纹。
- `media_source` 只负责下载编排，不作为评分证据组件，也不会让增量评估队列永久重复命中。
- 评估版本保留原有数据库唯一约束，并增加显式命名索引 `uq_evaluation_idempotency(content_id, rule_version, taxonomy_version, evidence_sha256)`。
- schema 升级到 v4；评估版本新增失效时间和原因。已存在的非证据响应污染版本保留原行并标记失效，所有当前评估、概览、内容、复核、报告与导出查询均排除失效版本。
- 抓取业务槽唯一键固定为内容或账号、阶段、窗口，不再包含 provider 和 adapter_version；适配器升级只能重试原失败槽，不能为同一业务窗口新开付费槽。
- HTTP 401/403 立即进入 `terminal_failed`，HTTP 402 保持可重试并触发余额熔断；408/429/5xx 保持可重试。
- 报告合同升级为 `dcar-content-operations-report-v8.1`：详情覆盖率 98%、评估覆盖率 95%、媒体终态覆盖率 95%、周报评论覆盖率 90%。
- 预估拉新、拉活、线索恢复为数量合同：单位分别为 `person/person/lead`；首版没有验证模型时恒为 `not_calculable` 且值为 `null`。
