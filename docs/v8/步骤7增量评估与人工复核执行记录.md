# 步骤 7：增量评估、卖点标准与人工复核

## 修改内容

- 新增数据库原生的证据封装与增量评估服务，评估版本只追加、不覆盖。
- 评论用户评分改为按证据版本增量 upsert，不再全表删除重建。
- 新增卖点词表草稿、增删改和原子发布服务；已发布版本保持不可变。
- 新增人工复核列表、领取和提交接口。人工证据进入 evidence-v1，产生
  `evaluation_source=manual_review` 的新评估版本。
- 内容页支持“待复核 / 补证”筛选和人工复核表单；卖点页支持草稿编辑、
  增删改及发布。
- 实际数据库完成 2 条新增媒体证据内容的增量评估：抖音内容 100 达到 V3，
  小红书内容 481 达到 V2。再次扫描时增量候选为 0。

## 本步骤发现并修复的问题

- 人工复核启动路由遗漏事务函数导入，已补齐并由 API 测试覆盖。
- `confirm` 复核原先可能保留 `pending_review=true`，已改为人工确认后明确结束待办。
- 复核列表的 `total` 原先表示分页返回数，已改为全量队列数，并单独返回 `returned`。
- 内容列表原先无法定位当前复核任务，已在查询模型中返回当前队列 ID 与状态。
