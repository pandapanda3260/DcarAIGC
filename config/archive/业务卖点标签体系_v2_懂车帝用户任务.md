# 业务卖点标签体系 v2：懂车帝用户任务口径

版本：2.0  
日期：2026-08-01  
修订原则：**卖点必须回答“用户通过懂车帝能完成什么”，不能只描述汽车内容本身有什么信息价值。**

## 一、命题4的新定义

> 命题4：这条内容是否清楚表达了用户可通过懂车帝完成的一项任务或获得的一项平台能力？主要是哪一项？

逐条输出：正式主卖点、核心/其他、匹配度与定性、平台承接证据、候选卖点、判断说明。

### 平台承接证据分级

| 级别 | 证据 | 是否可直接计入正式卖点 |
|---|---|---|
| A 明确承接 | 出现懂车帝具体模块、工具、服务、数据、页面、入口或行动引导 | 可以 |
| B 能力演示 | 内容本身完整演示懂车帝可持续提供的比较、测评、价格、车源或社区能力 | 可以，但匹配度通常低于 A |
| C 仅品牌露出 | 只有 `#懂车帝`、Logo、账号归属或一句品牌口播 | 不可以 |
| D 仅内容价值 | 泛汽车知识、汽车娱乐、情绪故事、单车夸赞，没有懂车帝能力 | 不可以 |

因此，“讲了汽车知识”不等于“懂车帝卖点”；“比较了两款真实车型并展示懂车帝对比能力”才可能是卖点。

## 二、正式卖点（严格口径）

### 二手车业务

| ID | 层级 | 修订后的标准标签 | 必须体现的懂车帝能力 |
|---|---|---|---|
| E1 | 核心 | 通过懂车帝卖车，由专业收车团队实现卖得高、到账快 | 懂车帝收车、上门评估、报价、成交或到账服务 |
| E2 | 核心 | 通过懂车帝购买海量靠谱二手车，查看透明车况并获得保障 | 懂车帝车源、检测报告、车况透明或平台保障 |
| E3 | 其他 | 通过懂车帝按预算和行情筛选高性价比二手车 | 懂车帝预算筛选、价格数据、车源比较或具体推荐能力 |
| E4 | 其他 | 通过懂车帝按人群和场景获得二手车推荐方案 | 懂车帝选车工具、推荐结果或场景化车源方案 |
| E5 | 其他 | 通过懂车帝查看检测报告、车辆档案或专业检测，识别问题二手车 | 懂车帝检测/档案/报告/鉴定能力；泛鉴别教程不直接计入 |

| E7 | 其他 | 通过懂车帝获得合同、过户、交易流程和权益保障 | 懂车帝交易服务、合同/过户辅助或平台保障 |

## 三、从未命中内容中观察的候选卖点

这些标签用于本轮“扩展口径”统计，尚未进入正式业务卖点，不参与正式核心占比。

| ID | 候选卖点 | 可承接的用户任务 | 与现有标签的边界 | 当前状态 |
|---|---|---|---|---|
| C1 | 通过懂车帝获取实用汽车知识和用车问题解答 | 学习驾驶、安全、零件、保养、维修和应急知识 | 不等于 M3/M5；后两者必须由AI小懂提供预约或诊断能力 | 候选，建议业务确认 |
| C2 | 通过懂车帝查看车型细节、真实影像和场景化体验 | 了解单车外观、内饰、空间、配置体验和使用场景 | 不等于 X2；没有独立实测或车主口碑。不等于 X5；没有版本对比 | 候选，建议与车型库能力核对 |
| C3 | 通过懂车帝车友社区交流用车体验并参与玩车内容 | 看车友内容、参与兴趣讨论、分享改装或车型创作 | 单纯情绪故事、汽车段子或品牌标签不算 | 候选，建议与车友圈目标核对 |
| C4 | 通过懂车帝跟踪新车发布和汽车行业动态 | 获取新车型、上市节奏、销量和行业资讯 | 价格/优惠归 X3；虚构概念车和无来源传闻不算 | 候选，需增加事实准确性门槛 |

### 不建议提炼为卖点的高频内容

- 汽车视觉娱乐、AI机甲/概念车幻想：用户任务不清楚，且不能稳定承接到懂车帝产品能力。
- 汽车情绪故事、豪车身份表达：主要提供情绪共鸣，不是懂车帝独有能力。
- 单车夸赞、重复铺量、泛“降价”标题但无价格或来源：不能因为发布量高就定义新卖点。
- 只有 `#懂车帝` 或 Logo 的内容：属于品牌露出，不是卖点证据。

## 四、评分与统计

| 分数 | 定性 | 规则 |
|---|---|---|
| 90–100 | 强匹配 | 平台任务、功能和用户收益均明确，主体持续展开 |
| 75–89 | 明确匹配 | 用户能清楚理解可通过懂车帝完成什么，证据充分 |
| 60–74 | 弱匹配待复核 | 有平台能力线索但承接入口、来源或主叙事不足 |
| 0–59 | 无正式卖点 | 只有品牌露出、汽车内容价值或证据不足 |

本轮同时输出：

1. **严格正式卖点覆盖率**：正式标签且通过阈值的内容数 ÷ 全部内容数。
2. **严格核心卖点占比**：核心正式标签且通过阈值的内容数 ÷ 全部内容数。
3. **候选卖点可解释率**：正式未命中但可被 C1–C4 稳定解释的内容数 ÷ 全部内容数。
4. **扩展后仍未命中率**：正式和候选都无法解释的内容数 ÷ 全部内容数。

正式核心比例仍以严格口径为准，不能把候选标签算进 60%–70% 目标。
